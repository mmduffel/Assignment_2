# Assignment_2

This repository contains two data analysis exercises completed using Python.

## Part 1: Used Cars

The first part uses a used-car dataset and includes:

- Missing value treatment
- Removal of measurement units
- One-hot encoding
- Feature engineering
- Data manipulation using pandas

## Part 2: Diabetes

The second part uses a diabetes dataset for additional data analysis.

## Repository Structure

- `Part1_UsedCars` – Used-car dataset and analysis
- `Part2_Diabetes` – Diabetes dataset and analysis
