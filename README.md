# Assignment_2

This repository contains two data analysis exercises completed using Python and pandas.

## Part 1: Used Cars

The first analysis uses a used-car dataset and focuses on data preprocessing and manipulation.

Tasks include:
- Missing value treatment
- Removal of measurement units
- One-hot encoding
- Feature engineering
- Select, filter, rename, mutate, arrange, group-by, and summarize operations

See the `Part1_UsedCars` folder for the complete analysis.

## Part 2: Diabetes

The second analysis uses a diabetes dataset containing 768 observations and focuses on sampling and statistical analysis.

Tasks include:
- Random sampling
- Sample and population comparisons
- Percentile analysis
- Bootstrap sampling
- Mean and standard deviation comparisons
- Data visualization

See the `Part2_Diabetes` folder for the complete analysis.
